チャットで Capri に頼むだけ。できることはこちら：

動画
• 「面白い動画を探して」や「アクションアニメを探して」：ぴったりのものを選んで再生します
• 「最新のを再生して」：チャンネルや番組の最新の投稿を再生
• 「一時停止」「30秒スキップ」「3:20に移動」「1.5倍速で再生」「次の動画」「字幕をオン」「ループして」
• 「全画面」や「動画を別ウィンドウで」

ブラウジング
• 「YouTube を開いて」や「Roblox のサイトを開いて」
• 「…をクリック」「下にスクロール」「戻って」「検索欄に hello と入力」してから「エンターを押して」
• 「YouTube のタブに切り替えて」「このタブを閉じて」「新しいタブを開いて」「このタブを左に移動」
• 「このページを要約して」「このページを読み上げて」「このページを翻訳して」
• 「このページは…について何て言ってる？」や「…を調べて」ですぐに答え
• 「何かランダムに見せて」や「ランダムなサイトを探して」
• 「これを保存して」でページを Speed Dial に追加

CAPRI RESEARCH（設定 > リサーチ）
• 「…をリサーチして」や「…を詳しく調べて」：あなたが他のことをしている間に、いくつものサイトを読みます（ブラウザが開いていれば彼女専用の隠れたビューで、あなたのタブや履歴には残りません）
• セーフサーチは常にオン。成人向けや危険な話題はリサーチしません
• 「一番いい…は？」でおすすめ、または「…に一番いいサイトは？」
• 「…か確かめて」や「…って本当？」
• 「タブを比べて」「どれを買うべき？」「何を開いてる？」
• Noted に質問・スクリーンショット・ファイルを置いて「最新のメモを解いて」と言う
• 「このページを見張って」や「値下がりしたら教えて」：20分ごとにチェックします
• 「このフォームに…を入力して」：パスワードやカード情報は絶対に入力せず、送信前に確認します
• 終わったら聞きます：表示する？メモに入れる？両方？
• 「リサーチを見せて」や「リサーチをメモに追加して」で直近の結果を

メモ
• 「メモに追加して…」「これをメモして」「それを書いといて」
• 「スクリーンショットを撮ってメモに入れて」
• 「このページを要約してメモに追加して」

ショッピング
• 「これをもっと安く探して」や「このサイトのクーポンコードある？」
• 「Roblox のゲームを探して」（Steam、itch.io など何でも）

メッセージ（設定 > Discord、オンにするまではオフ）
• 「Discord に新しいメッセージある？」：誰からかを伝え、あなたの「はい」で読み上げ、代わりに返信もできます
• 「Discord で Alex に…と送って」：入力して、送る前に確認します
• あなたの「はい」なしには何も送りません

ゲーム
• 「スネークしよう」「wiki race をやろう」「クイズを出して」
• wiki race では HELP を押すか「ヒントちょうだい」と言う。ゲームページで Easy・Hard・Challenging を選べます
• ゲーム、統計、実績はサイドバーに、Free Games This Week はゲームページにあります
• リーダーボード：名前を追加すると毎週のトップ100に参加できます。毎週月曜日に全員 0 からやり直し
• 累計の統計はあなただけのもの：リセットも送信もされません
• ゲームページの上部に注目ボックス（設定でオフにできます）

ブラウザで
• テキストを選んで右クリック：Ask Capri about this または Let Capri research this
• 変化のあったタブに戻ると、見逃した内容を教えてくれます
• ≡ メニューにはメモへのスクリーンショット、サイトのダークモード、動画のポップアウトがあります
• タブを右クリックして Add to bookmarks を選択。タブはドラッグで並べ替え
• 履歴には検索欄があります：直近7日・30日を削除、またはページを右クリックして削除
• 拡張機能：Chrome ウェブストアを開いて Add to Capri Browser を押すか、.zip や .crx ファイルを追加
• ≡ メニュー > Useful information に、はじめのヒントと Report a bug、Suggest an idea があります

設定で
• Capri の機能：一緒に見るときのリアクション、乗っ取りアニメーション、マウスの移動
• リサーチ：どれだけ深く調べるか、調べる前に聞く、ページの見張り、フォーム入力
• 動画プレーヤー：広告・オープニング・あらすじのスキップを提案（先に聞きます）、使うアニメ・動画サイト
• 外観：20のテーマと Capri スタイルの右クリックメニュー
• Update all で、あなたのバージョンに付属するすべてのゲームと言語をインストール
• 「Capri Browser の新機能は？」で最新の更新内容
