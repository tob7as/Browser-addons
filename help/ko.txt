채팅에서 Capri에게 편하게 말하면 돼요. 할 수 있는 일:

동영상
• "웃긴 영상 찾아줘" 또는 "액션 애니 찾아줘": 어울리는 걸 골라서 틀어 줘요
• "최신 거 틀어줘": 채널이나 프로그램의 최신 업로드
• "일시정지", "30초 건너뛰기", "3:20으로 가줘", "1.5배속으로 틀어줘", "다음 영상", "자막 켜줘", "반복 재생"
• "전체 화면" 또는 "영상 따로 띄워줘"

브라우징
• "YouTube 열어줘" 또는 "Roblox 웹사이트 열어줘"
• "... 클릭해줘", "아래로 스크롤", "뒤로 가줘", "검색창에 hello 입력해줘" 다음 "엔터 눌러줘"
• "YouTube 탭으로 가줘", "이 탭 닫아줘", "새 탭 열어줘", "이 탭 왼쪽으로 옮겨줘"
• "이 페이지 요약해줘", "이 페이지 읽어줘", "이 페이지 번역해줘"
• "이 페이지에 ...에 대해 뭐라고 써 있어?" 또는 "... 찾아봐줘": 빠른 답변
• "아무거나 보여줘" 또는 "랜덤 웹사이트 찾아줘"
• "이거 저장해줘": 페이지를 Speed Dial에 추가
• "유튜브 로고 찾아줘"나 "애니 프사 찾아줘": 세이프서치가 켜진 이미지 결과
• "화면 분할"(또는 탭 우클릭)로 두 탭을 나란히 보여줘요. 20분 동안 안 쓴 탭은 메모리를 아끼려고 잠들어요

CAPRI RESEARCH (설정 > 리서치)
• "...에 대해 리서치해줘" 또는 "... 자세히 알아봐줘": 하던 일을 계속하는 동안 여러 사이트를 읽어요 (브라우저가 열려 있으면 그녀만의 숨겨진 화면에서, 내 탭과 기록에는 남지 않아요)
• 세이프서치는 항상 켜져 있고, 성인용이나 위험한 주제는 리서치하지 않아요
• "가장 좋은 ...는 뭐야?": 추천 목록, 또는 "...하기 가장 좋은 사이트는?"
• "... 사실인지 확인해줘" 또는 "...라는 게 사실이야?"
• "내 탭들 비교해줘", "이 중에 뭘 사야 해?" 또는 "지금 뭐 열려 있어?"
• Noted에 질문, 스크린샷, 파일을 넣고 "내 마지막 메모 풀어줘"나 "내 학교 메모 풀어줘"라고 말하세요 (또는 메모 우클릭 > Work on this)
• "이 페이지 지켜봐줘" 또는 "가격 내려가면 알려줘": 20분마다 확인해요
• "내 페이지에 새로 바뀐 거 있어?": 지켜보는 페이지를 바로 확인해요
• "이 양식 ...로 채워줘": 비밀번호나 카드 정보는 절대 넣지 않고, 보내기 전에 물어봐요
• 끝나면 물어봐요: 띄울까요, 노트에 넣을까요, 둘 다?
• "내 리서치 보여줘" 또는 "내 리서치 노트에 추가해줘": 가장 최근에 찾은 것

노트
• "내 노트에 추가해줘 ...", "이거 메모해줘", "그거 적어줘"
• "스크린샷 찍어서 노트에 넣어줘"
• "이 페이지 요약해서 노트에 추가해줘"

커스텀 작업
• "open custom jobs" (또는 사이드바): "movie night" 같은 나만의 명령. 링크와 원하는 말로 쓴 단계를 넣을 수 있어요
• 단계에는 그녀의 어떤 명령이든 쓸 수 있어요. "check the comments", "ask Ready?" (네 대답을 기다림), "wait for it to load" 등. 작업에 여러 이름을 붙일 수 있어요: "movie night / film time"
• "make a job called movie night: open youtube.com, full screen", "what jobs do I have?", "delete my movie night job"

쇼핑
• "이거 더 싸게 찾아줘" 또는 "이 사이트 쿠폰 코드 있어?"
• "Roblox 게임 찾아줘" (Steam, itch.io, 뭐든지)

메시지 (설정 > Discord, 켜기 전까지는 꺼져 있어요)
• "Discord 새 메시지 있어?": 누가 보냈는지 말해 주고, 승낙하면 읽어 주고, 대신 답장도 할 수 있어요
• "Discord로 Alex한테 ... 보내줘": 입력하고 보내기 전에 물어봐요
• 승낙 없이는 아무것도 보내지 않아요

게임
• "스네이크 하자", "wiki race 하자", "퀴즈 내줘"
• wiki race에서는 HELP를 누르거나 "힌트 줘"라고 말해요; 게임 페이지에서 Easy, Hard, Challenging 선택
• 게임, 통계, 업적은 사이드바에, Free Games This Week는 게임 페이지에 있어요
• 리더보드: 이름을 추가하면 주간 톱 100에 참가해요; 매주 월요일에 모두 0부터 다시 시작
• 전체 기간 통계는 나만 볼 수 있어요: 초기화되지도, 전송되지도 않아요
• 게임 페이지 맨 위의 추천 상자 (설정에서 끌 수 있어요)

브라우저에서
• 텍스트를 선택하고 오른쪽 클릭: Ask Capri about this 또는 Let Capri research this
• 바뀐 탭으로 돌아오면 놓친 내용을 알려줘요
• ≡ 메뉴에 노트로 스크린샷, 사이트 다크 모드, 영상 팝아웃이 있어요
• 탭을 오른쪽 클릭해서 Add to bookmarks 선택; 탭을 끌어서 순서 변경
• 언제든 Esc를 누르면 조작을 멈춰요
• 기록에는 검색창이 있어요: 최근 7일, 30일 삭제, 또는 페이지를 오른쪽 클릭해서 삭제
• 확장 프로그램: Chrome 웹 스토어를 열고 Add to Capri Browser를 누르거나 .zip, .crx 파일 추가
• ≡ 메뉴 > Useful information에 환영 팁과 Report a bug, Suggest an idea가 있어요

설정에서
• Capri 기능: 같이 볼 때 반응, 장악 애니메이션, 마우스 움직이기
• 리서치: 얼마나 깊게 찾을지, 찾기 전에 묻기, 페이지 지켜보기, 양식 채우기
• 동영상 플레이어: 광고, 인트로, 요약 건너뛰기 제안 (먼저 물어봐요), 그녀가 쓰는 애니와 동영상 사이트
• 모양: 테마 20개와 Capri 스타일 오른쪽 클릭 메뉴
• Update all은 내 버전에 포함된 모든 게임과 언어를 설치해요
• "Capri Browser 새 기능 뭐야?": 최신 업데이트 내용
