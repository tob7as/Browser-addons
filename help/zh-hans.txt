在聊天里直接跟 Capri 说就行。她能做这些：

视频
• "给我找个搞笑视频" 或 "给我找部动作动漫"：她会挑一个合适的并播放
• "播放最新的"：播放某个频道或节目的最新一集
• "暂停"、"快进 30 秒"、"跳到 3:20"、"1.5 倍速播放"、"下一个视频"、"打开字幕"、"循环播放"
• "全屏" 或 "把视频弹出来"

浏览
• "打开 YouTube" 或 "打开 Roblox 官网"
• "点击 ..."、"往下滚"、"返回"、"在搜索框里输入你好"，然后 "按回车"
• "切换到我的 YouTube 标签页"、"关闭这个标签页"、"打开新标签页"、"把这个标签页往左移"
• "总结这个页面"、"把这个页面读给我听"、"翻译这个页面"
• "这个页面关于 ... 说了什么？" 或 "查一下 ..."：快速回答
• "给我看点随机的东西" 或 "找个随机网站"
• "收藏这个"：把页面存到 Speed Dial

CAPRI RESEARCH（设置 > 研究）
• "研究一下 ..." 或 "深入了解 ..."：你忙你的，她去读好几个网站（浏览器打开时在她自己的隐藏视图里读，不进你的标签页和历史记录）
• 安全搜索一直开着，她不会研究成人或危险话题
• "最好的 ... 是什么？" 看推荐，或 "做 ... 最好的网站是哪个？"
• "核实一下 ..." 或 "... 是真的吗？"
• "比较我的标签页"、"这些我该买哪个？" 或 "我开着什么？"
• 在 Noted 里放一个问题、截图或文件，然后说 "解决我最新的笔记"
• "盯着这个页面" 或 "降价了告诉我"：她每 20 分钟检查一次
• "用 ... 填写这个表单"：从不填密码或银行卡信息，提交前会先问你
• 完成后她会问：打开看看、存进笔记，还是都要？
• "打开我的研究" 或 "把我的研究加到笔记里"：查看她最近找到的内容

笔记
• "添加到我的笔记 ..."、"记下来"、"把那个写下来"
• "截个图放进我的笔记"
• "总结这个页面并加到我的笔记里"

购物
• "找个更便宜的" 或 "这个网站有优惠码吗？"
• "给我找个 Roblox 游戏"（或 Steam、itch.io，什么都行）

消息（设置 > Discord，打开之前一直关闭）
• "Discord 有新消息吗？"：她告诉你是谁发的，你同意后读出来，还能帮你回复
• "在 Discord 上给 Alex 发 ..."：她会打好字，发送前先问你
• 没有你的同意，她什么都不会发

游戏
• "来玩贪吃蛇"、"玩 wiki race"、"考考我"
• 在 wiki race 里按 HELP 或说 "给我个提示"；在游戏页面选 Easy、Hard 或 Challenging
• 游戏、统计和成就在侧边栏，Free Games This Week 在游戏页面
• 排行榜：添加一个排行榜名字，参加每周前 100 名；每周一大家都从 0 重新开始
• 全部时间统计只给你自己看：从不重置，也从不发送
• 游戏页面顶部的推荐框（可在设置里关闭）

浏览器里
• 选中文字后右键：Ask Capri about this 或 Let Capri research this
• 回到一个有变化的标签页，她会告诉你错过了什么
• ≡ 菜单里有截图到笔记、网站深色模式和弹出视频
• 右键标签页选 Add to bookmarks；拖动标签页来排序
• 历史记录可以搜索：删除最近 7 天、30 天，或右键某个页面删除它
• 扩展：打开 Chrome 网上应用店并点 Add to Capri Browser，或添加 .zip 和 .crx 文件
• ≡ 菜单 > Useful information 里有欢迎提示，还有 Report a bug 和 Suggest an idea

设置里
• Capri 功能：陪看反应、接管动画和移动鼠标
• 研究：她查得多仔细、查之前先问、盯页面、填表单
• 视频播放器：提议跳过广告、片头和回顾（她会先问），以及她用的动漫和视频网站
• 外观：20 个主题和 Capri 风格的右键菜单
• Update all 会安装你这个版本自带的所有游戏和语言
• "Capri Browser 有什么新功能？"：查看最新更新说明
