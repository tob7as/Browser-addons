在聊天裡用你自己的話告訴 Capri 就行。她能做這些：

影片
• 「幫我找個好笑的影片」或「幫我找部動作動畫」：她會挑一個合適的並播放
• 「播最新的」：播放某個頻道或節目的最新上傳
• 「暫停」、「快轉 30 秒」、「跳到 3:20」、「用 1.5 倍速播放」、「下一部影片」、「開字幕」、「重複播放」
• 「全螢幕」或「把影片彈出來」

瀏覽
• 「打開 YouTube」或「打開 Roblox 官網」
• 「點 ...」、「往下捲」、「上一頁」、「在搜尋框輸入你好」，然後「按 Enter」
• 「切到我的 YouTube 分頁」、「關掉這個分頁」、「開新分頁」、「把這個分頁往左移」
• 「摘要這個頁面」、「把這個頁面念給我聽」、「翻譯這個頁面」
• 「這個頁面對 ... 怎麼說？」或「查一下 ...」：快速回答
• 「給我看點隨機的東西」或「找個隨機網站」
• 「收藏這個」：把頁面存到 Speed Dial
• 「幫我找個 YouTube 標誌」或「幫我找個動漫頭貼」：開啟安全搜尋的圖片結果
• 「分割畫面」（或右鍵點擊分頁）讓兩個分頁並排顯示；20 分鐘沒用的分頁會休眠以節省記憶體

CAPRI RESEARCH（設定 > 研究）
• 「研究一下 ...」或「深入了解 ...」：你做你的事，她去讀好幾個網站（瀏覽器開著時在她自己的隱藏畫面裡讀，不進你的分頁和瀏覽紀錄）
• 安全搜尋一直開著，她不會研究成人或危險的主題
• 「最好的 ... 是什麼？」看推薦，或「做 ... 最好的網站是哪個？」
• 「查證一下 ...」或「... 是真的嗎？」
• 「比較我的分頁」、「這些我該買哪個？」或「我開了什麼？」
• 把問題、截圖或檔案放進 Noted，然後說「解答我最新的筆記」或「解答我的學校筆記」（或右鍵點擊筆記 > Work on this）
• 「盯著這個頁面」或「降價時告訴我」：她每 20 分鐘檢查一次
• 「我的頁面有新變化嗎？」：她會馬上檢查她在關注的頁面
• 「用 ... 填寫這個表單」：絕不填密碼或信用卡資料，送出前會先問你
• 完成後她會問：打開來看、存進筆記，還是都要？
• 「打開我的研究」或「把我的研究加到筆記」：查看她最近找到的內容

筆記
• 「加到我的筆記 ...」、「記下來」、「把那個寫下來」
• 「截個圖放進我的筆記」
• 「摘要這個頁面並加到我的筆記」

購物
• 「找更便宜的」或「這個網站有優惠碼嗎？」
• 「幫我找個 Roblox 遊戲」（或 Steam、itch.io，什麼都行）

訊息（設定 > Discord，開啟前一直關閉）
• 「Discord 有新訊息嗎？」：她會告訴你是誰傳的，你同意後念出來，還能幫你回覆
• 「在 Discord 傳給 Alex ...」：她會打好字，送出前先問你
• 沒有你的同意，她什麼都不會送出

遊戲
• 「來玩貪食蛇」、「玩 wiki race」、「考考我」
• 在 wiki race 按 HELP 或說「給我提示」；在遊戲頁面選 Easy、Hard 或 Challenging
• 遊戲、統計和成就在側邊欄，Free Games This Week 在遊戲頁面
• 排行榜：加一個排行榜名稱，參加每週前 100 名；每週一大家都從 0 重新開始
• 歷來統計只給你自己看：從不重設，也從不傳送
• 遊戲頁面頂部的精選方塊（可在設定裡關閉）

瀏覽器裡
• 選取文字後按右鍵：Ask Capri about this 或 Let Capri research this
• 回到有變化的分頁，她會告訴你錯過了什麼
• ≡ 選單裡有截圖到筆記、網站深色模式和彈出影片
• 在分頁上按右鍵選 Add to bookmarks；拖曳分頁來排序
• 隨時按 Esc 讓她停止接管
• 瀏覽紀錄可以搜尋：刪除最近 7 天、30 天，或在某個頁面按右鍵刪除
• 擴充功能：打開 Chrome 線上應用程式商店並按 Add to Capri Browser，或加入 .zip 和 .crx 檔案
• ≡ 選單 > Useful information 裡有歡迎提示，還有 Report a bug 和 Suggest an idea

設定裡
• Capri 功能：陪看反應、接管動畫和移動滑鼠
• 研究：她查得多仔細、查之前先問、盯頁面、填表單
• 影片播放器：提議跳過廣告、片頭和前情提要（她會先問），以及她用的動畫和影片網站
• 外觀：20 個主題和 Capri 風格的右鍵選單
• Update all 會安裝你這個版本附帶的所有遊戲和語言
• 「Capri Browser 有什麼新功能？」：查看最新更新說明

在分頁上按右鍵  複製、靜音、關閉其他
Ctrl+T  新分頁
Ctrl+Shift+N  私密分頁
Ctrl+W  關閉分頁（或按滑鼠中鍵）
Ctrl+Shift+T  重新開啟關閉的分頁
Ctrl+Tab  下一個分頁
Ctrl+Shift+PgUp / PgDn  把分頁左移 / 右移
Ctrl+L  在網址列輸入
Ctrl+F  在頁面中尋找
Ctrl+加號 / Ctrl+減號  縮放
Ctrl+P  列印
Ctrl+H  瀏覽紀錄
Ctrl+J  下載
F5  重新整理
F11  全螢幕
Ctrl+D  把這個網站加到 Speed Dial
Ctrl+Shift+S  Capri 摘要頁面
Ctrl+Shift+A  向 Capri 詢問這個頁面（或在網址列輸入 ?問題）
Ctrl+M  分頁靜音或取消靜音
Alt+左 / Alt+右  上一頁 / 下一頁
